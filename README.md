# Wokwi-projects

Collection of ESP32 mini projects built and simulated in [Wokwi](https://wokwi.com).

## Projects

| Project | Simulation |
|---------|------------|
| Turn on after pressing | [Open in Wokwi](https://wokwi.com/projects/454782267089957889) |
| Turn on while pressing | [Open in Wokwi](https://wokwi.com/projects/454488324102074369) |
| Turn on 7-seg display | [Open in Wokwi](https://wokwi.com/projects/455054551432609793) |
| 7-seg counter | [Open in Wokwi](https://wokwi.com/projects/454798281405892609) |
| A very simple thermometer | [Open in Wokwi](https://wokwi.com/projects/455069751303075841) |

## How to run

Open any link above and press the green **Start simulation** button. No hardware or installation needed.
